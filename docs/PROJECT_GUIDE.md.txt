# CNV Inspector Project Guide

# Project Purpose

본 프로젝트는 Android 스마트폰을 이용하여 컨베이어(CNV)의 비정상적인 진동 및 충격을 감지하고
CAD 도면 위에 위치와 충격을 시각화하는 Android Application이다.

본 프로젝트는 범용 솔루션을 목표로 한다.

PLC
AGV
CNV Controller
제조사 API

등은 사용하지 않는다.

오직

- Smartphone Camera
- IMU
- OpenCV

만 사용한다.

# Distance Estimation Policy

거리 계산은 아래 순서를 따른다.

Camera Frame

↓

ORB Feature Detection

↓

Lucas-Kanade Optical Flow

↓

Outlier 제거(RANSAC)

↓

Median Pixel Movement 계산

↓

Pixel → mm 변환

↓

누적 이동거리 계산

주의

평균(mean)은 사용하지 않는다.

Median 기반으로 계산한다.

Outlier 제거 후 거리 계산을 수행한다.

거리 계산은 반드시 Camera + Calibration 기준으로 수행한다.


# Calibration Policy

Calibration은 Session 기반으로 수행한다.

Frame Pixel은 사용하지 않는다.

CalibrationManager가 Pixel 누적을 관리한다.

DistanceEstimator는 Calibration 값을 계산하지 않는다.

CalibrationManager에서 조회만 한다.

흐름

Calibration Start

↓

Pixel Distance 누적 (세션)

↓

사용자가 실제 이동거리(mm) 입력

↓

mmPerPixel = realDistanceMm / sessionPixel

↓

Calibration 저장
