# CNV Inspector Architecture

## Layer

Presentation

↓

ViewModel

↓

Repository

↓

Core

↓

Feature Module (camera / opencv / imu / …)

↓

Platform

---

## Core Layer

```
core/
  event/      EventBus, Dispatcher, Publisher, Subscriber, *Event
  config/     AppConfig, CameraConfig, OpenCVConfig, IMUConfig, …
  common/     Result, State, Logger, TimeProvider, Dispatchers
  math/       MathUtil, CoordinateUtil
  model/      Shared DTOs (e.g. Vec3f)
```

공통 기능과 Event Driven 통신은 Core에서만 관리한다.

---

## MainActivity

MainActivity는 비즈니스 로직을 구현하지 않는다.

초기화·권한·화면 연결만 수행한다.

---

## Package / Feature Rule

| Package | 책임 |
|---------|------|
| camera | CameraX only |
| opencv | Vision / DistanceEstimator only |
| imu | IMU / Shock only |
| config (app) | CalibrationManager / Repository (feature service) |
| ui | Presentation |
| debug | Debug HUD |

Feature Module끼리는 **직접 참조하지 않는다**.

---

## Dependency Rule

**허용**

```
UI → ViewModel → Repository → Core → Feature
```

**금지**

```
Feature → Feature
Camera → IMU
IMU → Camera
OpenCV → CAD
CAD → OpenCV
```

Core EventBus를 통해서만 모듈 간 신호가 흐른다.

---

## Event Flow

```
DistanceEstimator ──publish──► DistanceEvent ──subscribe──► (Fusion future)
IMU ShockDetector ──publish──► ShockEvent     ──subscribe──► (Fusion / HeatMap future)
CalibrationManager ─publish──► CalibrationEvent
SystemEvent (APP_READY / FEATURE_*)
```

Camera와 IMU는 서로를 호출하지 않는다.

---

## Distance Estimator

Interface: DistanceEstimator

구현체: OpticalFlowDistanceEstimator → (future) FusionDistanceEstimator / AIDistanceEstimator

UI는 구현체를 직접 참조하지 않는다.

---

## Sensor Fusion (future)

IMU는 Camera를 대체하지 않고 보조한다.

Fusion은 Feature API를 호출하지 않고 Event만 구독한다.

---

## Calibration

Calibration 값은 Config + CalibrationManager로 관리한다.

Session 누적 Pixel 정책 (Decision 005).

---

## Thread

Camera / OpenCV / IMU / UI / Logging 은 독립 스레드에서 동작한다.

---

## Performance

GrayScale, ROI, Frame Skip, Object Pool, Bitmap reuse.

---

## Forbidden

- MainActivity에 OpenCV / IMU / 거리 계산
- UI에서 OpenCV 직접 호출
- Feature 간 직접 의존
