# CNV Inspector Architecture

## Layer

Presentation → ViewModel → Repository → Core → Feature (camera / opencv / imu / fusion / map / …) → Platform

## Core Layer

`core/event`, `core/config`, `core/common`, `core/math`, `core/model`

## Fusion Layer (STEP 09)

FusionEvent only. No Position. See [FUSION.md](./FUSION.md)

## Map Matching Layer (STEP 10)

Route topology + MapMatchingEngine. FusionEvent → PositionEvent. No CAD coords. See [MAP.md](./MAP.md)

## Future

- STEP 10-3 DWG / Route.json via RouteLoader
- STEP 11 CAD Viewer
- STEP 12 HeatMap

## Dependency Rule

Feature → Feature 금지. EventBus만 통신.

## Forbidden

MainActivity 비즈니스 로직, Fusion/RoutePosition에 CAD Position, 본 STEP DWG/CAD/HeatMap 구현
